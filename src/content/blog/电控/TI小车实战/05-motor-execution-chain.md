电机驱动和编码器组成了“输出—反馈”通道，控制算法负责闭合这条链。当前工程采用左右独立速度内环，并可在外层叠加位置控制、循迹修正和目标速度规划。

| 文档属性 | 内容 |
| --- | --- |
| 文档编号 | TI-CAR-05 |
| 内环 | 左右轮独立速度 PID + 前馈 |
| 外层 | 位置目标或循迹状态机 |
| 调度入口 | `Task_PID()`，周期 10 ms |
| 输出 | 左右带符号 PWM 命令 |

## 1. 为什么先有速度内环

同样的 PWM 在不同电量、负载和地面条件下不会得到固定转速。速度环比较目标 RPM 与编码器 RPM，并实时修正输出，使上层可以用“希望车轮多快”而不是“猜一个占空比”描述任务。

~~~text
目标 RPM ──┐
           ├→ 误差 → PID + 前馈 → PWM → 电机
实际 RPM ──┘                         ↑
      └──────── 编码器反馈 ─────────┘
~~~

左右轮分别保存滤波、积分、历史误差和输出状态。这样机械差异不会被一个平均控制器掩盖。

## 2. 实际速度如何滤波

`SpeedPID_Update()` 对实际 RPM 使用一阶低通：

~~~text
滤波值 += α ×（原始值 - 滤波值）
~~~

当前 `α` 在代码中配置为 `0.35`。较小的 α 更平滑但延迟更大，较大的 α 响应更快但保留更多波动。它是当前软件参数，不等于所有车辆和周期下的最佳值。

滤波放在控制模块而不是编码器驱动中，有两个好处：原始测量仍可诊断，控制器也能明确管理滤波初始化和复位。

## 3. PID 为什么带前馈

控制输出由目标前馈和误差反馈共同组成：

~~~text
输出 = Kf × 目标
     + Kp × 误差
     + Ki × 积分
     + Kd × 测量变化率
~~~

前馈先给出与目标速度成比例的基础输出，反馈再修正负载与模型误差。代码中的 D 项对测量变化率求导，避免目标突然变化时产生典型的微分冲击。

## 4. 抗饱和、死区和换向

当前实现包含多项工程保护：

- 输出限制在电机命令允许范围内。
- 积分只在误差进入指定范围时累积，并单独限幅。
- 输出饱和且积分会让饱和更严重时，不接受新的积分值。
- 目标和实际都接近零时，清积分并直接输出零。
- 目标跨越正负方向时，清积分和历史输出。

这些逻辑不是为了让公式更复杂，而是为了避免停车后残留积分、换向冲击和长期饱和。

## 5. 目标速度斜坡

`SpeedTarget_ApplyRamp()` 不允许目标 RPM 一步跳到最终值。它按控制周期限制每次变化量，加速和减速可使用不同速率；正反切换时先把目标拉回零。

~~~text
应用目标 → 限幅 → 判断加速/减速/换向 → 每周期最大步进 → PID 目标
~~~

斜坡限制的是“控制器收到的目标”，并不保证车轮一定按同样加速度运动。真实响应仍取决于电源、负载、地面和速度环参数。

## 6. 位置外环怎样生成速度目标

`PositionControl_Update()` 计算目标位置与当前距离的误差，再把位置误差转换为左右目标 RPM。远离目标时使用比例关系并限制最大速度；进入精调区域后使用较低速度；进入容差后目标归零。

~~~text
目标距离 - 当前距离
          ↓
      位置外环
          ↓
   左右目标 RPM
          ↓
   左右速度内环
~~~

位置环不直接输出 PWM。它只给速度环设目标，从而保留速度闭环对负载变化的补偿能力。

## 7. 三种位置判定口径

当前应用支持不同的位置模式：

| 模式 | 判定依据 | 适用含义 |
| --- | --- | --- |
| 平均模式 | 左右平均距离 | 关注车体整体位移 |
| 双轮模式 | 左右轮分别到达目标 | 关注两侧一致完成 |
| 左轮触发模式 | 左轮到达阈值 | 特定任务阶段触发 |

模式是应用策略，不应写入编码器驱动或 TB6612 驱动。底层始终只提供左右测量和左右输出。

## 8. 停稳不是“距离到了”

`PositionControl_IsAtTarget()` 除了检查位置误差，还要求左右实际 RPM 都进入停止范围。普通减速流程也要求目标斜坡与实际速度连续多个周期满足停止条件，之后才清理状态并禁止电机。

这避免车辆因为惯性刚越过距离阈值，就被错误判定为稳定完成。任务完成应同时包含：

~~~text
位置条件成立
+ 目标已降到零附近
+ 左右实际速度足够小
+ 连续满足稳定周期
~~~

## 9. 正确调参顺序

1. 验证 TB6612 方向和编码器反馈极性。
2. 固定低目标速度，只调单轮速度环。
3. 对比原始 RPM 与滤波 RPM，确定是否存在采样问题。
4. 调整前馈后再调 P、I，最后评估是否需要 D。
5. 速度环稳定后，才启用目标斜坡。
6. 最后调整位置外环的比例、限速、精调区和容差。

如果速度内环尚未稳定就调位置环，外层误差会掩盖内层问题，参数也难以迁移。

## 10. 控制接口与数据所有权

| 对象 | 主要写入者 | 主要读取者 |
| --- | --- | --- |
| `Encoder_Actual_Val[]` | Encoder 任务 | SpeedPID、停稳判断 |
| 位置目标 | PositionControl 接口 | PositionControl_Update |
| 左右目标 RPM | 位置/循迹应用 | Task_PID |
| PID 内部状态 | SpeedPID_Update | 串口诊断接口 |
| 左右 PWM | Task_PID | Motor BSP |

明确唯一写入者可以减少状态互相覆盖。新应用模式应生成目标 RPM，而不是绕过 `Task_PID()` 直接写电机。

## 本篇总结

- 左右轮各有独立速度内环，编码器 RPM 先低通，再进入前馈 PID。
- 目标斜坡负责限制命令变化，速度 PID 负责跟踪，位置外环负责把距离误差转换成速度目标。
- 限幅、条件积分、零速复位和换向清状态共同提高控制链的可控性。
- 调参必须从执行与反馈开始，按速度内环、目标规划、位置外环的顺序推进。
