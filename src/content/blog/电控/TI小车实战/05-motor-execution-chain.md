控制算法最终必须落到电机执行链。若方向、极性、PWM 量程或停机路径有一项不一致，再好的 PID 也只会把错误放大。本篇只讨论“命令怎样可靠地变成车轮动作”。

| 文档属性 | 内容 |
| --- | --- |
| 文档编号 | TI-CAR-05 |
| 输入 | 左右带符号 PWM 命令 |
| 输出 | TB6612 两通道方向与占空比 |
| 安全接口 | `set_motor_disable()` 与统一停机 |

## 1. 执行链全貌

```text
Task_PID
  → Load_Motor_PWM(left, right)
  → Motor_SetDuty(motor, command)
  → 命令限幅与通道极性
  → AIN/BIN 方向 GPIO + TIMA0 比较值
  → TB6612
  → 左右直流电机
```

上层使用“车辆坐标系”的正负方向，底层处理镜像安装造成的物理极性差异。这样位置控制和循迹算法不需要知道右电机端子是否与左侧相反。

## 2. 命令不是百分数

当前定义为：

```c
#define MOTOR_PWM_MAX 1000.0f
```

`Motor_SetDuty()` 会把输入限制在 `-1000` 到 `1000`。绝对值写入 PWM 比较值，符号决定方向。因此 `100` 约为满量程的十分之一，不是 100%。

接口文档应始终同时写出单位或量程。只写“占空比 100”会让接手者误判十倍。

## 3. 左右轮极性

当前配置中，左轮输出极性为 `+1`，右轮为 `-1`。这是对左右电机镜像安装的适配：相同的正向车辆命令，在底层可能产生相反的电机端子方向。

验证极性时只建立一个坐标约定：从车尾向车头为前进正方向。依次检查：

1. 左轮正命令是否推动左侧向前；
2. 右轮正命令是否推动右侧向前；
3. 正向转动时对应编码器 RPM 是否也为正；
4. 两轮同正命令时车辆是否直行趋势一致。

不要为了“让轮子看起来转对”同时修改输出极性和编码器极性。一次只改一层，并记录修改前后的符号表。

## 4. TB6612 控制表

| 通道 | PWM | 方向信号 | 当前接口 |
| --- | --- | --- | --- |
| 左轮 A | PWMA | AIN1 / AIN2 | PB14，PB5 / PB10 |
| 右轮 B | PWMB | BIN1 / BIN2 | PA7，PB7 / PB6 |
| 公共使能 | — | STBY | PB8 |

方向 GPIO 决定 H 桥导通方向，PWM 调节平均输出，`STBY` 控制驱动器待机。软件停机不应只依赖某一项：先将两路 PWM 清零，再把 `STBY` 拉低，能够减少状态残留风险。

## 5. 初始化为什么先零输出

`Motor_Start()` 的关键顺序是：

1. 启动电机 PWM 与 QEI 计数器；
2. 初始化编码器复用和计数基线；
3. 将 `STBY` 配置为输出并拉低；
4. 写入左右 PWM 为零；
5. 最后拉高 `STBY`。

这个顺序避免外设初始化时比较寄存器或 GPIO 处于未定义状态就驱动电机。任何修改都应保留“先禁用、再零输出、最后允许”的原则。

## 6. 分层验证执行链

### A. 逻辑层

在不接电机的情况下，验证零命令、正命令、负命令和超范围命令的限幅结果。检查左右实际命令数组是否与输入一致。

### B. 波形层

示波器观察 PWMA/PWMB 和方向脚。确认：

- 两路 PWM 周期一致；
- 命令绝对值增大时有效占空比单调变化；
- 改变符号时方向脚切换；
- 零命令时没有意外脉冲；
- 停机时 `STBY` 进入预期状态。

### C. 架空单轮

一次只连接一侧电机，以低命令、短时间运行。记录转向、空载电流、噪声、供电压降和停止行为。

### D. 双轮架空

给相同车辆正向命令，确认两轮机械方向一致，MCU 不复位，编码器反馈符号一致。

### E. 低速落地

只有前四层通过后才落地。先开环短距离，再进入速度闭环；不要用 PID 调参掩盖接线或极性问题。

## 7. 停机的三种语义

| 类型 | 适用场景 | 当前动作重点 |
| --- | --- | --- |
| 正常减速 | 任务完成、希望平滑停车 | 目标速度斜坡归零，确认实际速度稳定 |
| 逻辑中止 | 按键取消、模式切换 | 清状态、清 PWM、拉低同步信号 |
| 紧急断能 | 接线异常、失控、人员风险 | 硬件断开电机电源，不等待软件 |

软件正常停车不能替代实体急停。反过来，硬件断电后软件也必须重新建立状态，不能假设任务仍可从中断点继续。

## 8. 常见故障矩阵

| 现象 | 优先检查 | 不应先做 |
| --- | --- | --- |
| 一侧完全不转 | STBY、供电、PWM、方向脚、接线 | 先加大 PID |
| 正命令向后 | 输出极性或电机端子 | 同时改编码器极性 |
| 启动时 MCU 复位 | 电源压降、共地、反灌、干扰 | 提高 PWM |
| 零命令仍抖动 | PWM 波形、方向切换、驱动状态 | 直接落地测试 |
| 左右相同命令不直 | 机械差异、供电、反馈与标定 | 假设纯软件问题 |

## 本篇总结

- 电机执行链接受 `-1000` 到 `1000` 的带符号命令，符号控制方向，绝对值控制 PWM 量级。
- 左右轮镜像安装差异由 BSP 的输出极性吸收，上层始终使用统一车辆坐标系。
- 初始化和停机都遵循先禁用、清零输出、再允许或断能的顺序。
- 执行链要按逻辑、波形、单轮、双轮、落地逐层验证；接线与极性未确认前，不应进入 PID 调参。
