## 1. 概念与功能

教材对应的8位、8通道逐次逼近ADC；多路模拟选择器一次选一路，SAR逐位判断，数字结果经三态锁存缓冲器读出。8路输入不等于8路同时转换。当前未核实考试直接指定此型号。

## 2. 符号图与端口

| 端名（脚号） | 作用 |
| --- | --- |
| IN0～IN7（26、27、28、1～5） | 8路模拟输入，选一路进行转换 |
| ADDA／ADDB／ADDC（25、24、23） | 通道地址，A为最低地址位 |
| ALE（22） | 高有效地址锁存允许 |
| START（6） | 启动脉冲，上升沿清SAR、下降沿启动转换 |
| EOC（7） | 转换结束输出，高电平表示结束 |
| OE（9） | 输出允许，高电平将已转换结果送到数字输出 |
| CLOCK（10） | 转换时钟 |
| $2^{-1}\sim2^{-8}$ | 8位数字输出，$2^{-1}$最高位；具体脚号见图 |
| $V_{\mathrm{CC}}$／GND（11／13） | 电源／地 |
| $V_{\mathrm{REF}}(+)/V_{\mathrm{REF}}(-)$（12／16） | 参考范围两端 |

## 3. 真值表与功能表

按教材文字整理，不冒充教材未列出的完整手册时序表。

| 动作 | 结果 |
| --- | --- |
| 设通道地址，ALE有效 | 锁存地址，选择对应模拟输入 |
| START上升沿 | SAR清零 |
| START下降沿 | 开始逐次比较；教材要求启动脉冲宽度大于100ns |
| EOC为高 | 转换结束，结果已锁存 |
| OE为高 | 可读数字输出；OE为低时不驱动输出总线 |

教材举$+5\mathrm V$供电、640kHz时钟的使用情况；这不是所有ADC的统一时钟条件。

## 4. 驱动、输出与状态方程

**外部控制条件**：地址稳定后ALE选通／锁存；START脉冲上升沿清SAR、下降沿启动。等待本次转换结束，再用OE读出；不能仅看到旧EOC高就把上一次结果当新结果。

**SAR算法行为**（理想模型，非0809内部逐时钟网表）：从MSB到LSB试置1；若试探DAC电压不超过输入则保留，否则清除。参考范围$V_R=V_{\mathrm{REF}}(+)-V_{\mathrm{REF}}(-)$，8位名义LSB为$V_R/256$。

**输出关系**：OE＝0时输出Z；OE＝1时输出最近锁存的转换结果。EOC说明是否完成，OE不启动转换。端点码与具体量化区间应按手册／题图，不编造统一的floor公式。

**状态关系边界**：只知教材外部控制，不能据此给内部SAR每个D触发器写驱动；转换时间也不自动等于8个CLOCK。

## 5. 状态转移表

此处是外部使用阶段表，不是全部内部SAR状态表。

| 使用阶段 | 外部操作／事件 | 后续阶段与结果 |
| --- | --- | --- |
| 待用 | 地址稳定，ALE有效 | 所选通道地址锁存 |
| 通道已选 | START脉冲 | 发起转换 |
| 转换中 | 本次EOC结束指示成立 | 结果已锁存 |
| 结果可读 | OE=1 | 总线读到结果 |
| 读完 | OE=0 | 总线高阻，可开始下次操作 |

EOC由内部产生，图表不把它当软件可写控制端。

## 6. 状态转移图

外部转换／读数操作流程，非宣称ADC0809内部只有这些离散状态。


## 8. 级联与例子

**通道扫描复合例**：控制器依次送地址000…111，每次完成后读一个字节，8次构成一轮；若自编条件给每通道“切换＋转换＋读出”合计100µs，则一轮800µs，每通道采样率1.25kS/s。是时间复用，输出仍8位。

若用两片组成16输入系统，需分别控制通道与START，数字总线共接时只允许所读片OE有效；这不是把两个8位输出拼成16位分辨率，也不能两个OE同时开启。

## 9. 常考题型与例题分析

以下题为**通用SAR**，不表示它们使用ADC0809：

1. **数试探步骤与转换时间**：核对初始置零、逐位比较以及结束控制需要几个时钟。<span title="引用资料不在本次上传范围，尚未发布至网站">习题册11-5（8位通用SAR）<small>（本地资料未发布）</small></span>
2. **从电压砝码波形读结果**：从MSB起逐次判断留1／清0，再按题给位数写代码。<span title="引用资料不在本次上传范围，尚未发布至网站">2018春·一7（6位SAR）<small>（本地资料未发布）</small></span>
3. **区分分辨率、速度与采样条件**：位数决定量化级数，采样频率和转换周期另核验。<span title="引用资料不在本次上传范围，尚未发布至网站">习题册11-1(3)～(5)<small>（本地资料未发布）</small></span>

> [!tip] 易混点
> 8通道是输入可选通道数，8位是输出码宽；EOC是结束指示，OE是输出允许，START是转换启动，作用不能互换。ADC0809不能代替所有逐次逼近电路的计时模型。

**真实训练：习题册11-5（通用SAR，非0809专题）。** $f=250kHz$，每周期4µs。原答案给36µs，对应9周期；教材图10.4.7的完整控制循环则为$(n+2)T$，8位对应40µs。应先明确计时从“哪一事件”到“结果有效／回初态”，不可统一成32、36或40µs用于所有结构。<span title="引用资料不在本次上传范围，尚未发布至网站">题册答案12-5，原PDF55<small>（本地资料未发布）</small></span>

**自编核验例（非真题）**：参考0–5V，输入恰1.25V，对理想SAR，试码80H的2.5V应清；40H的1.25V保留，其余低位再试都会超出；最终01000000＝40H。此为算法演示，不指定0809每个内部时钟的试码时间。
