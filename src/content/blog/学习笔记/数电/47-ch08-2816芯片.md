## 1. 概念与功能

电擦除、电编程的非易失EEPROM，单片2K×8bit。与EPROM比较，差别在擦写方式；容量／总线线数可从题干确定，不能据名称推编程电压或脉宽。

## 2. 符号图与端口

| 信息 | 要点 |
| --- | --- |
| 容量 | $2\mathrm K\times8\mathrm{bit}$，题干与教材共同确认 |
| 地址线 | $\log_2 2048=11$根 |
| 数据线 | 8根；读写时按控制信号决定方向 |
| 类别 | 电擦除、电编程的非易失存储器 |

## 3. 真值表与功能表

本材料没有2816专用引脚功能／编程时序表。下表只列类别操作规则，不能把“写请求”视作某个已知引脚边沿。

| 操作 | 地址／数据 | 存储内容 | 外部读出 |
| --- | --- | --- | --- |
| 读 | A稳定 | M不变 | M[A] |
| 写请求及编程过程 | A、D按所用器件要求保持 | 完成前不据此宣布新数据有效 | 不作为有效读 |
| 编程完成后读 | 同一A | 所写字更新，其余保持 | 新M[A] |
| 掉电保存 | — | 已完成内容保留 | 上电按有效读操作获取 |

## 4. 驱动、输出与状态方程

**驱动条件**：实际型号规定的读／写操作；本资料未列写入握手及引脚时序，不补造。

**输出方程**：有效读时$D_{\mathrm{out}}=M[A]$。

**存储行为**：在一个有效写操作**完成后**，$M^+[A]=D_{\mathrm{in}}$，其他地址$M^+[a]=M[a]\ (a\ne A)$；普通读$M^+=M$。这不是可直接当作HDL时钟更新的硬件方程。

**容量**：$2^{11}\times8=16384\mathrm{bit}=2\mathrm{KB}$。

## 5. 状态转移表

不枚举$2^{16384}$种存储内容；用外部操作表说明完成前后，既不宣称内部只有三个状态，也不假定有BUSY输出引脚。

| 操作阶段 | 允许得出的结论 |
| --- | --- |
| 原内容有效 | 可读旧字节 |
| 写请求／等待 | 等待器件规定的完成条件；不能指定固定延时 |
| 完成 | 所选地址已写成新字节 |
| 再次读 | 在读操作成立后取得新字节 |

## 6. 状态转移图

外部操作流程，不是芯片内部硬件状态机。

```mermaid
flowchart LR
A["读旧数据"] --> B["发起有效写操作"]
B --> C["等待型号规定的完成条件"]
C --> D["重新读并核验"]
D --> A
```

## 8. 级联与例子

**位扩展例（存储组织层面）**：两片2816同地址读出，低片A5H、高片3CH分别接两组独立8位数据线，合成16位字3CA5H；容量2K×16＝32Kbit。写操作需由所选型号电气时序分别满足，不能由本逻辑例子推定两片能用任意相同写脉冲。

**容量扩展例**：两片由互斥片选选择，形成4K×8；高位地址选择片号，低11位片内寻址。

## 9. 常考题型与例题分析

1. **由容量数总线线数**：$2\mathrm K=2^{11}$个字对应11根地址线，8位字长对应8根数据线。<span title="引用资料不在本次上传范围，尚未发布至网站">2016秋·一4<small>（本地资料未发布）</small></span>
2. **同题容量单位核对**：2K×8bit＝16Kbit＝2KB；数据位数不参与地址线数量的对数计算。<span title="引用资料不在本次上传范围，尚未发布至网站">2016秋·一4<small>（本地资料未发布）</small></span>

> [!tip] 易混点
> 已核实的2816指定题支持容量／总线线数考法；不要移用2864A容量、引脚编号或编程时序。

**真实例题：2016秋·一4。** 考容量到线数换算。①把2K写成$2^{11}$字；②地址数决定11根地址线；③每字8bit决定8根数据线。关键结果11、8。易错：对总16384bit取对数会错算地址线。

**自编核验例（非真题）**：4片扩成8K×8，共65536bit＝8KB，新增2位片选地址，片内仍11位；若改成2K×32，则4片同时被选中且各驱动独立数据位组。
