## 1. 概念与功能

静态RAM，单片2K×8bit；可正常读写，工作中无需DRAM式刷新，但掉电丢失。数据端双向，必须防止读输出与外部写数据同时驱动总线。

## 2. 符号图与端口

| 题图端名 | 要点 |
| --- | --- |
| $A_{10}\sim A_0$ | 11位片内地址，单片2K个字 |
| $D_7\sim D_0$ | 8位双向数据线，容量2K×8bit |
| $\overline{CS}$ | 低有效片选，接高位地址译码输出 |
| $\overline{WE}$、$\overline{OE}$ | 低有效写入／输出允许，题图接/WE与/RD |

## 3. 真值表与功能表

按题图端名整理基本读写，不替代详细时序表。

| $\overline{CS}$ | $\overline{WE}$ | $\overline{OE}$ | 数据线 |
| --- | --- | --- | --- |
| 1 | × | × | 未选中，不驱动总线 |
| 0 | 0 | 1 | 向所选地址写入 |
| 0 | 1 | 0 | 从所选地址读出 |
| 0 | 1 | 1 | 输出关闭 |

未列$\overline{WE}=0,\overline{OE}=0$为推荐写法：为保证示例总线无争用，写时令OE无效；详细写时序应另查具体厂商。

## 4. 驱动、输出与状态方程

**控制条件**：$R=\neg\overline{CS}\land\overline{WE}\land\neg\overline{OE}$；推荐示例的写条件$W=\neg\overline{CS}\land\neg\overline{WE}\land\overline{OE}$。符号$\overline{WE}$是端口的逻辑值，写时该值为0。

**输出方程**：读使能时$D_{\mathrm{bus}}=M[A]$；输出关闭时芯片对总线为Z，写时总线由外部驱动。

**存储关系**：有效写周期完成后$M^+[A]=D_{\mathrm{in}}$，其余字保持；普通读不改M。这是写周期完成后的关系，不保证写脉冲期间保持旧字，也不是假定内部有CP的同步RAM。

## 5. 状态转移表

完整存储内容不枚举；下表为外部读写周期关系。

| 当前操作 | 后续事件 | 对M的影响 |
| --- | --- | --- |
| 读 | 地址稳定／变更 | 保持；输出对应所选字 |
| 写 | 有效写周期完成 | 更新该地址一个字节 |
| 保持／未选中 | 仍未选中 | 保持，输出不驱动 |
| 任意 | 掉电 | 不保证保存 |

## 6. 状态转移图

外部操作流程，不是芯片内部硬件状态机。

```mermaid
flowchart LR
A["先关闭读输出"] --> B["地址与外部写数据稳定"]
B --> C["完成有效写周期"]
C --> D["外部停止驱动总线"]
D --> E["开启读输出核验"]
E --> A
```

## 8. 级联与例子

**真实字扩展接法**：2020春图1.2，8片共接A10…A0及8位数据总线，A13…A11接74138选择输入，A14接高有效使能、A15接低有效使能；片选互斥。得到16K×8＝131072bit，寻址4000H–7FFFH。区间长度4000H＝16384字。

**自编位扩展例**：两片共片选，分别接低／高8位，得到2K×16bit；地址010H两片分别5A／C3H，合成C35AH。直接并接两片相同数据位不是位扩展。

## 9. 常考题型与例题分析

1. **识别字扩展并算容量**：8片共用8位数据总线、逐片选择，总容量8×2K×8bit，字长仍为8。<span title="引用资料不在本次上传范围，尚未发布至网站">2020春·一7<small>（本地资料未发布）</small></span>
2. **由译码推寻址区间**：先用使能端限定$A_{15},A_{14}$，再使片选地址$A_{13}\sim A_{11}$及片内地址$A_{10}\sim A_0$遍历，求首尾地址。<span title="引用资料不在本次上传范围，尚未发布至网站">2020春·一7图1.2<small>（本地资料未发布）</small></span>

> [!tip] 易混点
> SRAM工作中不需DRAM式刷新，但掉电仍丢失；数据总线共接不等于位扩展，要看多片是否同时选中。

**真实例题：2020春·一7。** ①由A0…A10得每片2048字；②8片逐片选择，增加字数不增字长；③使能条件给A15A14＝01；④令其余14位从全0到全1，得4000H–7FFFH。题目总容量单位是bit，结果131072bit。

**自编核验例（非真题）**：4片2K×8扩为8K×8，从8000H开始连续映射，则地址尾=8000H+2000H−1=9FFFH；还需上位地址译码保证区外不误选。
