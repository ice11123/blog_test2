# 证据、隐私与硬件安全

## 断言模板

在研究笔记中使用以下最小记录格式：

| 断言 | 状态 | 证据 | 适用范围 | 待确认项 |
| --- | --- | --- | --- | --- |
| 示例：PWM 由某定时器输出 | 已由代码确认 | 初始化函数与调用点 | 当前构建配置 | 引脚实测波形 |

状态只能使用：`已由配置确认`、`已由代码确认`、`仅发现文件`、`已由实测确认`、`待确认`。

## 常见误判

- 驱动文件存在，不等于被编译或链接。
- 函数已定义，不等于被可达调用链调用。
- 宏在头文件中定义，不等于当前活动配置启用。
- README 写有某型号，不等于当前实物板卡就是该版本。
- 注释给出频率，不等于时钟树、分频与实测结果一致。
- 示例工程能编译，不等于目标硬件接线与供电安全。
- 仿真或串口日志成功，不等于闭环控制在负载下稳定。

## 敏感信息

文档生成前主动排除：

- API token、访问密钥、私钥、证书和 Wi-Fi 密码。
- 私有仓库地址、内网地址、个人手机号、邮箱和设备唯一标识。
- 比赛尚未公开的题目资料或用户明确要求保密的算法。

发现疑似凭据时只报告文件位置和风险类型，不回显值。除非用户明确授权，不自动删除或轮换。

## 上电与运动安全

文档涉及电机、电源、驱动器、舵机、电池或执行机构时，至少覆盖：

- 供电电压、逻辑电平、极性与额定电流必须来自对应原理图/数据手册；无法确认时停止给出具体接线结论。
- 首次上电使用可限流电源，并从保守限流开始；具体限值需由硬件资料确定。
- 明确共地、反接保护、短路检查和接口插拔条件。
- 首次电机测试架空车轮或解除机械负载，并预留物理断电路径。
- 闭环调试先限制占空比、速度或输出幅度；阈值必须来自用户配置或实测，不臆造数字。
- 描述故障现象时区分软件停机、驱动器保护与人工断电。

安全段落必须与项目相关，避免复制一份看似完整但未经板卡资料验证的固定清单。

## 外部资料

- 优先使用芯片厂商、工具厂商、器件制造商和项目上游的官方资料。
- 记录资料标题、版本、适用器件/板卡与访问日期。
- 社区文章可用于发现线索，不作为关键电气参数的唯一依据。
- 外部资料与工程配置冲突时，先确认器件/板卡版本；不要擅自选择一个答案。
