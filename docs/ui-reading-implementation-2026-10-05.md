# blog2 视觉反馈与阅读交互实施验收

日期：2026-10-05。源码起点为 `aeee1e6b9453e57bef39ce73cdccd1ddf2da7ecd`，本次验证对象是其后的本地未提交工作树，不是线上部署。实施追踪使用 Beads `blog_test2-glr`；本文记录设计与证据，不代替任务状态。

## 改动与设计依据

按照 Emil 的信息边界、可感知反馈、键盘立即响应与降低动态标准实施。不引入 React、动画库或运行时依赖，不复制 astro-koharu 源码。

| Before | After | Why |
| --- | --- | --- |
| 星图电控素材侵入文章入口 | 信息安全区与素材舞台分离，保留 3D | 以空间契约解决遮挡，不删图或取消效果 |
| 两侧均称文章目录，长标签省略 | 全站目录／本文目录；完整标签与本地过滤 | 区分找文章和找章节，降低查找成本 |
| 三项侧栏只切换浅背景 | 固定等宽活动底板与轻量面板衔接 | 当前状态明确，键盘即时、不等待动画 |
| 系列聚合仍叫近期文章，底部入口无独立反馈 | 近期更新；主体与完整目录分别反馈 | 两个目的地不能依赖同一种整卡反馈 |
| 搜索加载与失败不明确 | 五种状态与原位重试、键盘提示 | 不抢焦点，失败后仍能完成搜索 |
| 手机需要反复打开目录确认当前位置 | 紧凑章节／进度／目录入口 | 复用现有 TOC 几何和唯一滚动调度，避免重复扫描 |
| 正文图片不能放大，长系列没有公共上下篇 | 按需图片查看器与目录同序的系列导航 | 补阅读闭环，不改源 Markdown 或学习顺序 |
| 手机目录在视觉上打开但真实点击被遮罩截获 | 移动布局解除桌面的隔离层叠上下文 | DOM 触发不能代替真实点击测试 |

新增图片查看器关闭时保留滚动条槽、恢复阅读位置和焦点；路由切换释放事件、弹层与滚动锁。跳转链接中的图片保留原始链接，不被查看器接管。

导航层、内容层、浮层采用语义 surface／elevation 变量；1100–1279px 文章减少无效内外边距，左右栏继续保留。壁纸状态机、三层波浪、主题圆形切换、磨砂、伪 3D 均未删除或改参数。

## 浏览器与验收证据

使用工作区已有 Playwright 与本机 Edge（Chromium）无头浏览器，没有新增项目依赖。测试地址为本地生产预览 `http://127.0.0.1:4337/blog_test2/`。

- `scripts/perf/verify-reading-ui.mjs`：1440、1100、1024、390、320px × 亮暗主题，检查星图素材边界、文章宽度、真实目录点击、当前章节、进度及系列链接。矩形验证不是主观动画顺滑的替代。
- 同脚本验证标签过滤、键盘活动底板、搜索网络失败与重试、无结果、图片缩放与关闭焦点／位置恢复、路由清理、正文图片失败恢复及降低动态模式。
- `scripts/perf/verify-topic-atlas.mjs`：首页卡片 3D 与子文章入口独立反馈回归。
- `scripts/perf/measure-directory-motion.mjs`：CPU×4，真实点击三轮展开／收回，捕获点击到稳定状态的 rAF、Long Task 和 DevTools Layout/Paint trace，单独保存每轮数据。
- 截图与精简结果位于 `artifacts/performance/reading-ui-2026-10-05/`；原始 trace 压缩保存，截图和压缩 trace 不加入项目运行时。

最终功能回归通过 10 组断点／主题组合和全部交互用例，运行时异常记录为空。降低动态实测发现打开状态的抽屉选择器覆盖了原本的立即切换规则，已补齐相同优先级的关闭／打开规则并通过复测，普通模式仍为原来的 240ms 抽屉动画。

质量结果：`pnpm test` 的 142 项根测试与 30 项 Worker 测试全部通过；`pnpm run check` 为 0 错误、0 警告，保留既有输入法兼容代码的 1 个 `keyCode` 提示；`pnpm run build` 完成 224 页；额外执行 `pnpm run postbuild` 验证 11 篇高数笔记的链接、锚点与附件；`git diff --check` 通过。Worker 只跑既有测试，没有源码改动或部署。

`verification.json` 同时记录基线提交和改动源码 SHA-256，避免把未提交工作树的截图误称为线上提交证据。功能通过与目录性能 `withinBudget: false` 独立记录。

## 目录性能：尚未全部达标

第一次宽窗口测量最大帧约 105.5ms。排除页面启动与滚动干扰后，CPU×4 的三轮精确测量仍在首次展开发现约 133.4ms 的帧间隔和 134ms 长任务，其中同步 Layout 峰值约 110.9ms；后续五次操作没有长任务，最大帧在约 11.1–27.8ms。

上述数字是同机器的一次采样，不是设备保证或整站 INP。Trace 指向首次为隐藏列表计算固有尺寸的开销，而不能据此证明每一帧高度动画都产生百毫秒卡顿。

仅通过实验样式进行了四种对照：关闭 pretty 排版、离屏 content-visibility、布局 containment、grid 改 flex。均未稳定消除首次峰值，因此没有把它们合入业务样式；离屏估算还会引入高度变化风险。

保留现有目录展开效果及其可反向交互。本轮新增测量工具与明确的 `withinBudget` 结果，不以功能测试成功冒充性能通过。进一步的一次布局／合成展开方案需要覆盖多个分组同时切换、背景边缘、页脚位置与焦点，不适合未经回归直接替换。该性能项继续由 Beads 追踪。
