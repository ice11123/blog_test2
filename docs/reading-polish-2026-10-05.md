# 阅读导航、搜索与首页优化验收

日期：2026-10-05。仅 blog_test2；不修改 GUET428、Worker 或云发布开关。

## 改动依据

参考 astro-koharu 的布局层级与按需加载思路，不复制其源码。保持三层波浪、壁纸抽屉、磨砂、主题圆形过渡和现有文章内容。

| Before | After | Why |
| --- | --- | --- |
| 首页近期四项被同一维护系列占据 | 按二级系列聚合，附索引入口、最新日期和完整目录 | 提供内容发现，完整目录原顺序不变 |
| 目录是按钮，点击后地址没有章节信息 | 真实锚点、hash、标题焦点和当前位置 | 支持复制、刷新定位及移动侧栏阅读衔接 |
| 每次滚动逐一测量标题 | 几何失效时更新缓存，滚动二分定位 | 将工作移出滚动热路径，而不是删除动画 |
| 搜索内联索引、上下键重建列表 | 版本化静态索引按需加载，局部更新选中项 | 降低首载、换页和键盘操作成本 |

## 实测

同一 Chrome 无 CPU 限速环境，1440×900，文章“高等数学第 17 章：空间解析几何与向量分析”，22 个标题。等待字体与布局稳定后运行 120 次连续滚动。

| 指标 | 线上基线 f64e84d | 本地优化版 |
| --- | ---: | ---: |
| 标题 getBoundingClientRect 调用 | 2640 | 0 |
| 目录锚点 | 0 | 22 |
| 有效帧间隔样本 | 119 | 119 |
| p95 帧间隔 | 5.7 ms | 5.7 ms |
| 最大帧间隔 | 12.3 ms | 5.7 ms |
| Long Task | 0 | 0 |
| 横向溢出 | 0 | 0 |

结论仅限本次采样：显著减少滚动路径的标题测量，不能据此宣称所有设备都达到同一帧率。早期测试浏览器发生异常帧等待，已丢弃；未把工具阻塞当成页面性能结论。本次没有重新测量 CPU×4、真实 Android、全站 LCP/INP 或弱网。

## 交互回归

- 搜索前未请求正文索引；首次搜索仅请求一次。中文组合期间方向键不拦截、不选中结果；连续八次方向键的列表 childList 变更为 0。
- 正文查询“方向余弦”命中第 17 章并显示完整词附近的片段。等待期间关闭搜索或换页不会写入旧结果。
- 章节链接点击后 hash、标题焦点与 aria-current 对应同一章节；修正浏览器整像素滚动导致的半像素高亮偏差。
- 390px 移动左栏打开后焦点移入、正文 inert；Escape 恢复正文并归还箭头焦点。右栏点击章节后关闭，焦点留在标题。
- 320px、390px、1100px、1440px 检查无横向溢出；23px 可见侧栏箭头保留，透明触摸区域为 44px。
- 连续十次快速反向点击壁纸后收起，抽屉无 inert 残留，暂停动画为 0；顶栏与左栏位置不变。
- 近期文章和系列目录的八个入口均返回 200；索引入口和完整目录互不嵌套。

## 架构与验证边界

壁纸控制器只管理状态与生命周期；图片模块维护解码资格、主题切换和失败重试；时间线模块维护轨迹、进度及反向采样。首次几何初始化、稳定收起及页面卸载均释放暂停动画，避免长抽屉成为常驻合成层。

TOC 观察直接正文块及文章/顶栏尺寸；图表内部的逐帧 style/class 绘制不会刷新全部标题。正文结构变化会重新观察新增块。

质量门禁：Node 根测试 136 项、Worker 测试 30 项；Astro check 无错误/警告，保留一个兼容旧输入法的 keyCode 弃用提示；224 页面构建及 11 篇高数笔记链接、锚点和附件验收通过。提交发布时再次检查 git diff --check。
