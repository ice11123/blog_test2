# 首页主题与标签发现改版（2026-10-06）

本次实现依据 `docs/astra-ui-deep-review-2026-10-06.md` 与 `docs/ui-tools-and-design-direction-2026-10-06.md`，应用 emil-design-eng 的信息层次、入口与反馈一致、键盘即时响应和渐进披露规则。实现由用户指定的 GPT-6.1-sol 完成；提交、发布和部署由主代理统一处理。本文记录实现与已取得的验证，不作为任务清单。

## 改动依据

源码文章标签统计为 151 个，其中 28 个出现在多篇文章，123 个仅出现于一篇。最高频标签为 MSPM0G35XX（12 篇）、高等数学（11 篇）与 TI小车（10 篇）。首屏常用区取多篇标签中按实际篇数降序的前 16 个；剩余 135 个包含另外 12 个多篇标签，因此区名为“更多标签”，不误称“单篇标签”。相同篇数按中文名称稳定排序，标签名称与真实 URL 保留。

| Before | After | Why |
| --- | --- | --- |
| 卡内编号、截断英文眉题、中文标题、篇数竞争，上半区最小高度在移动端仍为 180px | 中文标题与篇数形成第一层，完整简介为第二层，近期区使用“近期文章”；移动端取消上半区与卡片固定最小高度 | 分类识别应先于装饰；文字决定移动高度，避免空白占据学习入口 |
| 电源空主题显示“等待第一篇记录”，仍带近期英文标题 | 使用“内容准备中 · 暂无文章”，省略无内容的近期标题，保留分类入口 | 空主题仍可发现，同时准确说明状态 |
| Codex、小车、书本、电源线图与档案素材的舞台和视觉体积不同 | 素材保持，舞台桌面统一 130px、小屏统一 96px；线图宽度与档案纸片比例整理，保留原旋转、深度和 hover 参数 | 统一空间关系，比更换技术主题素材更符合已有博客识别 |
| 近期文章行有独立链接，但焦点反馈未专门定义 | 分类大区域保留既有 3D hover/按压反馈；近期文章行用独立红色 hover、按压与清楚的 focus-visible | 所见反馈与实际去向一致，两个真实链接是兄弟关系，避免嵌套链接 |
| 近期卡标签为不可点击 span，但使用类似标签入口的药丸背景 | 改为轻量文字与间隔点，文章主入口保持 | 元数据不应伪装为另一个独立操作 |
| 总览平铺全部 151 个标签 | 改为总量、全量搜索、常用区、原生更多区；增强后每批 24 个，独立“查看全部”一次展开 | 同时支持知道名称的检索与不知道搜什么的发现；无需缩小字号堆满标签 |
| 标签总览与详情传入构建时 new Date()，呈现文章日期式标题 | 聚合页不再生成发布日期；详情显示标签名称、文章数与“返回全部标签”，下方文章布局不变 | 构建时间不是标签发布时间，聚合页首先说明范围与数量 |

## 实现结构

`src/lib/tagDiscovery.ts` 封装实际篇数、常用分组、全量过滤及披露数量规则。计数采用 Map，并对单篇文章的重复标签去重，避免安全键名与重复篇数问题。搜索与侧栏复用同一 NFKC、首尾空白和大小写匹配逻辑；规范化只用于检索，不用于改写标签或路由。

`TagDiscoveryLink.astro` 负责真实 href、名称、篇数及独立交互状态。标签总览每个标签只渲染一次；无 JavaScript 时，原生 details 的更多区仍包含全部其余标签。仅在脚本成功初始化后显示搜索工具与渐进展开按钮，避免提供无响应的搜索框。

`tag-discovery.ts` 在 Astro page-load 初始化，在 before-swap 中取消该页监听；重复初始化先清理上一次绑定。中文输入法组合期间不重排；提交后立即过滤全部标签。查询命中折叠区时自动展开，清空时恢复查询前的折叠状态；清空按钮回到输入框，键盘逐批展开可进入新增标签，最后一批按钮消失时转交焦点。未增加持续 rAF、定时器、动效库或新运行时依赖。

公共内容布局的 pubDate 可省略，日期区域仅在 showDate 为真且存在真实 pubDate 时呈现。文章布局及现有文章日期数据不变。原有三层波浪 12/7/4 秒、主题圆形过渡、壁纸抽屉、磨砂、分类顺序、文章原文与配色和 Worker 均未修改。

## 主代理实际交互复验

Codex 内部浏览器成功打开本地 Astro 构建预览。实际点击已确认分类整卡与卡内近期文章分别进入分类页和正文；标签页可检索未披露的 WAAPI 标签，空匹配提示正确，清空恢复查询前折叠状态并将焦点交还输入框。逐批展开后显示 64 个标签（16 个常用加 48 个更多），查看全部后显示全部 151 个；标签结果显示真实篇数，并可返回目录。

1440×900、390×844 和 320×568 的页面均无横向溢出，明暗主题切换正常。320px 统计实读为“151／个标签／50 篇文章”，无孤字。实体触摸、降低动态设置和帧率尚未实测，不宣称通过。复验发现并修复三项显示细节：原生更多区展开后提示改为“收起标签”，窄屏统计拆成有意义的两行，三种 SVG 按固有比例适配舞台，保留旋转与悬停反馈及裁切安全区。

SVG 首次适配的纯几何公式未涵盖 CSS Grid 隐式轨道：实际父容器虽为 130px，自动轨道仍达到 163.812px，导致百分比高度超出预期。随后对三种素材明确使用 `minmax(0, 1fr)` 行列轨道，避免固有尺寸撑大。此例说明源码契约与数学边界不能替代浏览器实际布局测量。

最终内部浏览器实测：桌面轨道 130px、Codex SVG 高度 106.6px；移动轨道 96px、SVG 高度 78.7125px。图案完整，页面无横向溢出。最终本地截图归档于 `artifacts/ui-implementation-2026-10-06/`，与先前参考站研究截图分开。

线上访问可通过当前进程的 `http://127.0.0.1:7897` 代理进行 HTTP 检查；内部浏览器没有公开代理配置入口，线上标签页虽有标题与 URL，但读取其 DOM 仍超时。本地交互证据不等同于线上点击验收，部署结果需另外通过 GitHub Actions 与线上资源确认。
